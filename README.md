#  Iron Spirit — Sitio Web de Gimnasio 💪

Proyecto de sitio web completo para un gimnasio, desarrollado con **HTML, CSS y JavaScript puro** como parte de mi aprendizaje en desarrollo web.

---

##  Vista general

Sitio web moderno, oscuro y responsive para el gimnasio **Iron Spirit**, con diseño profesional, animaciones CSS, secciones interactivas, optimizado para máximo rendimiento en PageSpeed.

---

##  Tecnologías utilizadas

| Tecnología | Uso |
|---|---|
| HTML5 | Estructura semántica y contenido |
| CSS | Estilos, animaciones, clip-path y responsive design |
| JavaScript (Vanilla) | Interactividad y funcionalidades dinámicas |
| Font Awesome 6 | Íconos |
| Google Fonts | Tipografía (Montserrat) |

---

##  Secciones del sitio

| Sección | Descripción |
|---|---|
| **Header** | Barra de navegación fija con efecto glassmorphism y menú hamburguesa responsive |
| **Home** | Hero sin imágenes — tipografía gigante, slash diagonal rojo con `clip-path`, stats y efecto parallax al mover el mouse |
| **Instalaciones** | Carrusel automático con 4 slides, barra de progreso, dots y swipe táctil |
| **Servicios** | 6 tarjetas de servicios con imagen de fondo y efecto hover en rojo |
| **Entrenadores** | 10 entrenadores en cards con acordeón expandible — perfil, especialidad, horario, certificaciones y clases grupales |
| **Tienda** | 9 productos filtrados por categoría (Suplementos, Ropa, Equipos) sin recargar la página |
| **Precios** | 3 planes de membresía con toggle mensual/anual y cambio de precio dinámico |
| **Contacto** | Formulario con confirmación + datos del gym + redes sociales + footer |

---

##  Funcionalidades destacadas

- ✅ Diseño **100% responsive** (mobile, tablet, desktop)
- ✅ **Hero sin imágenes** — construido con CSS puro (clip-path, gradientes, tipografía) para máxima puntuación en PageSpeed
- ✅ Menú hamburguesa con cierre automático al hacer scroll o clic externo
- ✅ Carrusel automático con pausa al hover y swipe táctil
- ✅ **Sección de entrenadores** — 10 perfiles con acordeón animado (uno abierto a la vez)
- ✅ Filtro de productos por categoría en tiempo real
- ✅ Toggle de precios mensual/anual con cambio dinámico
- ✅ Formulario con mensaje de confirmación
- ✅ Efecto parallax en el título hero al mover el mouse
- ✅ Scroll suave entre secciones
- ✅ Animaciones CSS puras (sin librerías externas)

##  Personalización

Para adaptar el sitio a tu gym, edita estas variables en `style.css`:

```css
:root {
    --color-main: #ff0800;      /* Color principal (rojo) */
    --bg-main:    #141418;      /* Fondo oscuro */
    --white:      white;
    --tarjetas:   #0000007a;    /* Fondo de tarjetas */
}
```

##  Aprendizajes del proyecto

Durante el desarrollo de este proyecto practiqué y apliqué:

- Estructura semántica con HTML5
- Variables CSS y diseño con Flexbox y Grid
- `clip-path` para formas geométricas y elementos decorativos
- Animaciones y transiciones con CSS puro
- Manipulación del DOM con JavaScript (IIFE, IntersectionObserver, classList, data-*)
- Patrón de acordeón con `max-height` para animaciones suaves
- Carrusel con autoavance, touch events y barra de progreso
- Diseño responsive con media queries
- Optimización de rendimiento (hero sin imágenes, `loading="lazy"`)
- Organización y documentación de código
